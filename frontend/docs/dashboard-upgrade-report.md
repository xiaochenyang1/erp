## 🚀 使用指南

### 快捷操作
1. **顶部快捷按钮**：点击直接新增采购/销售或查询库存
2. **统计卡片**：点击跳转到对应功能页面（待实现）
3. **图表时间切换**：点击"近7天/近30天"切换数据展示
4. **待办事项**：点击"处理"按钮直接处理任务
5. **快捷入口**：点击图标快速访问常用功能
6. **库存预警**：点击"查看全部"跳转预警页面

### 访问地址
```
http://localhost:5173/dashboard
或
http://localhost:5173/  (默认首页)
```
