# ERP 当前开发状态与财务报表二期候选（2026-11-11）

## 结论

一期候选 PR #18 已于 2026-11-10 合并到 `main`，merge commit 为 `1e1f6c5fe4c75a3faef3271213b938c89dcd6a6f`。多层分仓 MRP、生产成本核算和有限产能排程一期已经进入主分支；仓库仍没有对应 tag、GitHub Release 或真实预生产业务签字，因此“已合并”不等同“已正式发布”。

当前分支 `feature/phase2-financial-statements` 已实现财务报表二期最小管理报表能力：试算平衡、资产负债表、利润表、直接法现金流量表、账套级科目映射、校验结果和 CSV 导出。该分支目前是开发候选，不是发布候选；必须完成 MySQL 8.4、全量 CI、真实浏览器和部署验证后，才能进入预生产签字。

## 当前实现范围

| 能力 | 已实现范围 | 边界 |
|---|---|---|
| 试算平衡 | 按期间汇总期初、本期借贷和期末借贷，检查借贷平衡并支持 CSV | 只统计已进入账簿的凭证分录 |
| 资产负债表 | 按 V175 `TYPE_MAPPING_V1` 聚合账套级科目映射，检查资产与负债权益勾稽 | 管理报表最小版，不是法定格式 |
| 利润表 | 按期间汇总收入、费用和净利润，并与资产负债表权益侧累计利润勾稽 | 暂不包含法定报表的全部展示项目和附注 |
| 现金流量表 | V176 `CASH_FLOW_DIRECT_V1` 直接法，配置现金范围及对方科目分类，检查期初、净流量和期末现金 | 间接法尚未开发；内部现金转账不计入现金流量 |
| 配置与校验 | 账套级报表科目、现金科目和现金流对方科目映射；未映射、重复、类别不匹配和失效科目进入校验结果 | 新增科目必须由具备会计科目管理权限的人员显式配置 |
| 前端与导出 | `/finance/ledger` 统一展示总账、明细账、试算平衡和三张报表；支持映射维护和 CSV 下载 | CSV 会携带口径版本与核对状态，校验失败不能当成已核对报表 |

设计口径见 [财务报表二期设计](superpowers/specs/2026-11-10-financial-statements-phase2-design.md)，迁移边界见 [迁移历史](migrations-history.md)，人工验收见 [财务报表验收清单](FINANCIAL-STATEMENTS-ACCEPTANCE-2026-11-11.md)。

## 产品边界

- 当前资产负债表、利润表和现金流量表是 `TYPE_MAPPING_V1` / `CASH_FLOW_DIRECT_V1` 管理报表最小版，不冒充企业会计准则要求的完整法定格式。
- 现金流量表只实现直接法主表；间接法补充资料尚未开发。
- 固定资产、完整税务、法定报表附注、合并报表和多级抵销不在本期范围。
- 自动化验证只能证明程序口径和勾稽关系，不能替代财务人员对真实科目映射、期初数据和报表列报的确认。
