# 有限产能排程一期说明（2026-11-08）

## 定位

本期在现有生产工单、工艺路线和工作中心基础上提供确定性的有限产能排程，用于回答三件事：待执行工序何时开始和结束、工作中心在所选区间内是否超负荷、哪些工序因前置关系或产能约束预计延期。

当前实现是轻量制造排程，不宣称为完整 APS。预览不会修改业务数据；执行会把本次结果写入工单工序快照，并保留审计证据。

## 输入与规则

- 候选工单状态：`RELEASED`、`MATERIAL_ISSUED`。
- 候选工单计划开始日期不得晚于排程结束日期。
- `DONE` 工序不重复排程；剩余负荷按 `标准分钟 × max(计划数量 - 已报工数量, 0)` 计算。
- 工单按计划完工日期、计划开始日期、工单号排序，执行最早交期优先（EDD）。
- 同一工单的未完成工序严格按工序序号串行。
- 同一工作中心同一时刻只分配一道工序，不能超过每日容量。
- 工作日按工作窗口的开始日判断为周一至周五；周末开始的窗口自动跳过。夜班窗口可自然跨过午夜，因此周五开始的夜班可以延伸到周六，但不会在周六新开一个工作窗口。
- 工作中心默认每日容量 480 分钟、08:00 开工，可在工作中心维护页调整为 1–1440 分钟及任意每日开工时间。
- 单次排程区间最长 366 天。

若工序跨多个工作日，容量计算会跳过非工作时段；当前响应中的开始/结束时间是整个工序的时间包络，不拆成逐日工时段明细。

## 结果与异常说明

排程结果包括：

- 工单数、工序数、已排、未排和延期数量；
- 每个工作中心的区间工作日容量、已排分钟数和负荷率；
- 每道工序的剩余数量、标准工时、所需分钟、排程开始/结束、产能等待分钟和延期分钟；
- 未排原因，包括工作中心不存在或已停用、标准工时无效、区间产能不足、前置工序未排入计划。

停用工作中心不会进入产能汇总，但引用它的工序仍会作为未排工序返回，并给出原因。延期仅表示排程结束时间晚于工单计划完工日，不自动修改工单交期。

## 接口、权限与数据快照

- `POST /api/production/schedules/preview`：预览，权限 `production:schedule:view`。
- `POST /api/production/schedules/run`：执行并写入快照，权限 `production:schedule:run`。
- 排程会读取并竞争整个账套的工单与工作中心容量，因此预览和执行都要求登录态具备 `ALL` 数据范围；仅有仓库、部门、岗位或本人范围的账号直接拒绝，避免泄露隐藏工单或生成忽略隐藏负荷的错误计划。
- 请求字段：`startDate`、`endDate`。
- 工作中心新增：`daily_capacity_minutes`、`workday_start_time`。
- 工单工序新增：`standard_minutes`、`scheduled_minutes`、`scheduled_start_time`、`scheduled_end_time`、`scheduled_by`、`scheduled_time`。
- 每次执行重算所有候选未完成工序；本次未排入计划的工序会清空旧排程字段，避免保留过期快照。
- 执行结果写入 `PRODUCTION_SCHEDULE / RUN` 审计日志，快照包含完整排程响应。

前端入口为“生产管理 → 产能排程”，支持日期区间、预览、执行确认、工作中心负荷和工序明细查看。

## 一期明确边界

本期暂不包含：

- 法定节假日、调休、停机、加班及工作中心例外日历；
- 多班次、班组、人员技能、设备模具、物料齐套时间等多资源约束；
- 换线/换模时间、批量合并、最小批量、转运时间和并行工序；
- 基于成本、延期、换线次数等目标函数的全局优化；
- 拖拽式人工锁定、冻结区、局部重排及版本方案对比；
- 逐日工序分段甘特图和实时设备执行反馈。

因此验收表述应使用“确定性有限产能排程一期”，不能表述为“完整 APS 已完成”。若后续需要班次日历或多资源优化，应先扩展产能日历和资源模型，再调整算法及排程快照结构。

## 自动化覆盖

- 算法测试覆盖同中心争用、工序前置、周末跳过、区间产能不足、延期、非法区间及停用中心汇总。
- 服务测试覆盖预览不落库、执行写入、旧快照清空、统计口径、审计证据，以及仓库/部门/岗位/本人等受限数据范围在读取工单前被拒绝。
- 控制器测试覆盖预览/执行权限、请求校验和 HTTP 响应。
- 前端测试覆盖 API 数值/Long ID 归一化、预览、执行、取消、错误处理、工作中心产能字段和中英文文案。
- UI smoke 新增两张同工作中心工单的预览/执行闭环，并校验排程时段无重叠、工序快照和审计日志。

真实预生产仍需使用目标环境的班次约定、工作中心容量和代表性工单数据执行人工验收；当前自动化结果不能替代业务计划员签字。
