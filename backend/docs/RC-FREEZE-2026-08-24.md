## 证据归档规则

Maven `clean` 会删除 `backend/target`，因此 `target/**` 只作为临时构建输出，不得作为唯一的 RC/发布证据。权威证据必须写入独立目录，例如：

```bash
export ERP_EVIDENCE_DIRECTORY="$PWD/release-evidence/rc-20260824-<commit>"
export ERP_FQ_EVIDENCE_DIRECTORY="$ERP_EVIDENCE_DIRECTORY/fq-signoff-api-check"
```

PowerShell 脚本的 `-EvidenceDirectory`、`-OutputPath`、`-ReportDirectory` 参数应指向同一独立证据根目录。证据目录需在执行 `clean` 前后保留，并在发布包或受控制品库中归档。
