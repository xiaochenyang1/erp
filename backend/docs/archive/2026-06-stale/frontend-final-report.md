## 💻 技术实现亮点

### 1. 复杂业务流程
```typescript
// 采购订单审批流程
草稿 → 提交 → 待审核 → 审核通过/驳回 → 已完成

// 采购收货流程  
选择订单 → 自动带出明细 → 修改实收数量 → 选择仓库 → 完成收货
```

### 2. 关联数据处理
```vue
<!-- 收货单关联订单 -->
<el-select v-model="form.orderId" @change="handleOrderChange">
  <el-option 
    v-for="order in availableOrders" 
    :key="order.id"
    :label="`${order.orderNo} - ${order.supplierName}`"
  />
</el-select>

<!-- 自动带出订单明细 -->
form.items = order.items.map(item => ({
  productId: item.productId,
  orderedQuantity: item.quantity,
  quantity: item.quantity // 默认全部收货
}))
```

### 3. 实时数据统计
```typescript
const draftCount = computed(() => 
  tableData.value.filter(item => item.status === 'DRAFT').length
)
const completedCount = computed(() => 
  tableData.value.filter(item => item.status === 'COMPLETED').length
)
```

### 4. 状态驱动UI
```vue
<!-- 根据状态显示不同操作 -->
<el-button v-if="row.status === 'DRAFT'" @click="handleComplete">
  完成收货
</el-button>
<el-button v-if="row.status === 'DRAFT'" @click="handleCancel">
  取消
</el-button>
```
