# 生产成本核算 1.0

## 成本口径

- 材料成本以生产领料和退料的实际库存金额为准。
- 人工成本由工单成本归集单录入，过账为借记 `5001 生产成本`、贷记 `2211 应付职工薪酬`。
- 制造费用由工单成本归集单录入，过账为借记 `5001 生产成本`、贷记 `5101 制造费用`。
- 归集可关联工序，但工序不作为必填维度。

## 完工分摊

材料、人工、制造费用分别按同一数量比例计算：

```text
本次某类完工成本
= (某类累计投入 - 某类累计已完工成本)
× 本次完工数量 / 剩余可完工数量
```

本次数量等于剩余可完工数量时，直接结转全部剩余金额，避免尾差。完工单保存三类成本快照，其合计与完工入库、完工凭证金额一致。

## 反完工

反完工总额取成品库存实际出库金额，不重算历史单价。总额按工单当前未冲回的完工材料、人工、制造费用占比拆分，反完工单保存拆分快照。库存加权平均价与原完工成本的差额保留在工单在制中，后续完工再结转，以保证业务账与 `5001` 科目勾稽。

## 在制与勾稽

```text
累计投入 = 材料投入 + 人工归集 + 制造费用归集
在制成本 = 累计投入 - 累计完工成本
勾稽差额 = 在制成本 - 5001 科目按工单单据来源汇总的净借方
```

已完工工单仍允许补录成本，但报表标记为“成本差异”，不将其视为已平衡。

## 1.1 冲销与更正

- 已过账的正向归集单不可删除或直接修改。冲销生成一张负向归集记录，并按原成本类型生成反向凭证：人工为借记 `2211`、贷记 `5001`，制造费用为借记 `5101`、贷记 `5001`。
- 原归集单改为 `REVERSED`，冲销记录通过 `reversal_of_entry_id` 指向原单；同一原单只能冲销一次。
- 更正在同一事务内完成“冲销原单 + 新增替代归集单”，替代单通过 `correction_of_entry_id` 指向原单，可继续被后续更正，从而形成完整审计链。
- 冲销/更正日期不得早于原归集日期，且所选日期必须处于开放会计期间；操作使用独立的 `production:order:cost:reverse` 权限。
- 工单人工/制造费用累计额按冲销和替代金额同步调整。已完工成本快照保持不可变，因此完工后发生的差额继续体现在在制/成本差异中，并与 `5001` 净额保持勾稽。
