# 生产成本核算 1.0

## 成本口径

- 材料成本以生产领料和退料的实际库存金额为准。
- 人工成本由工单成本归集单录入，过账为借记 `5001 生产成本`、贷记 `2211 应付职工薪酬`。
- 制造费用由工单成本归集单录入，过账为借记 `5001 生产成本`、贷记 `5101 制造费用`。
- 归集可关联工序，但工序不作为必填维度。

## 完工分摊

材料、人工、制造费用分别按同一数量比例计算：

```text
本次某类完工成本
= (某类累计投入 - 某类累计已完工成本)
× 本次完工数量 / 剩余可完工数量
```

本次数量等于剩余可完工数量时，直接结转全部剩余金额，避免尾差。完工单保存三类成本快照，其合计与完工入库、完工凭证金额一致。

## 反完工

反完工总额取成品库存实际出库金额，不重算历史单价。总额按工单当前未冲回的完工材料、人工、制造费用占比拆分，反完工单保存拆分快照。库存加权平均价与原完工成本的差额保留在工单在制中，后续完工再结转，以保证业务账与 `5001` 科目勾稽。

## 在制与勾稽

```text
累计投入 = 材料投入 + 人工归集 + 制造费用归集
在制成本 = 累计投入 - 累计完工成本
勾稽差额 = 在制成本 - 5001 科目按工单单据来源汇总的净借方
```

已完工工单仍允许补录成本，但报表标记为“成本差异”，不将其视为已平衡。

## 1.1 冲销与更正

- 已过账的正向归集单不可删除或直接修改。冲销生成一张负向归集记录，并按原成本类型生成反向凭证：人工为借记 `2211`、贷记 `5001`，制造费用为借记 `5101`、贷记 `5001`。
- 原归集单改为 `REVERSED`，冲销记录通过 `reversal_of_entry_id` 指向原单；同一原单只能冲销一次。
- 更正在同一事务内完成“冲销原单 + 新增替代归集单”，替代单通过 `correction_of_entry_id` 指向原单，可继续被后续更正，从而形成完整审计链。
- 冲销/更正日期不得早于原归集日期，且所选日期必须处于开放会计期间；操作使用独立的 `production:order:cost:reverse` 权限。
- 工单人工/制造费用累计额按冲销和替代金额同步调整。已完工成本快照保持不可变，因此完工后发生的差额继续体现在在制/成本差异中，并与 `5001` 净额保持勾稽。

## 1.2 成本关单与差异结转

- 只有状态为 `COMPLETED` 且成本关单状态为 `OPEN` 的工单可以关单。关单日期不得早于最近完工或成本归集日期，并且必须位于开放会计期间。
- 关单差异按“累计投入 - 累计完工成本 - 已结转差异”计算。正差异生成借记 `5102 生产成本差异`、贷记 `5001 生产成本`的凭证；负差异方向相反。历史完工入库及已结转销售成本保持不变。
- 零差异同样生成不可变关单流水并锁定工单，但不生成金额为零的凭证。关单后报表中的剩余在制为零，状态为 `CLOSED`，5001 按工单来源汇总的净额同步归零。
- 已关单工单禁止新增成本归集、冲销或更正，也禁止反完工。需要后续调整时必须先反关单。
- 反关单日期不得早于原关单日期，且必须位于开放期间。系统把原关单流水标记为 `REVERSED`，新增一条反向流水和反向凭证，恢复原成本差异及 5001 净额；原流水和原凭证均不删除、不改写。
- 关单与反关单分别使用 `production:order:cost:close` 和 `production:order:cost:reopen` 权限。每次操作的业务日期、金额、原因、操作者及关联流水均可追溯。

## 1.3 期间批量关单与月结门禁

- 生产订单页提供期间批量关单入口。预览按会计期间截止日筛选已完工、成本状态仍为 `OPEN`，且最近完工/成本业务日期不晚于期末的工单；同时汇总正差异、负差异和净差异。
- 期间列表、预览、执行和审计证据统一使用生产成本关单权限；成本会计无需额外取得财务期间维护权限即可使用批量关单入口。
- 批量关单统一使用期间结束日作为业务日期，单次最多处理 100 张工单。每张工单继续复用 1.2 的加锁、期间校验、差异结转和凭证逻辑，并使用独立事务执行，因此并发关单、状态变化或数据权限问题只影响对应工单，不回滚同批次已成功结果。
- 接口返回逐单成功/失败、关单号、结转差异和失败原因。批次汇总及全部逐单结果写入 `sys_audit_log`，业务类型为 `PRODUCTION_COST_PERIOD_CLOSE`、动作为 `BATCH_CLOSE`；生产订单页可按期间查看当前操作人的最近审计证据，审计管理员仍可在系统审计日志中查询租户内完整记录。
- 会计期间月结检查新增 `PRODUCTION_COST_UNCLOSED`。期间截止日前仍存在未成本关单的已完工工单时，锁定和结账均被阻断；批量关单完成后检查项转为通过，并进入既有月结快照证据链。
- 预览和执行沿用 `production:order:cost:close` 权限，并继续遵守生产工单数据范围。月结检查按当前公司和账簿执行全量租户内检查，不受操作员生产数据范围缩小影响。
