## 已完成的行为修复

| 范围 | 当前行为 |
|---|---|
| 合同查询、详情、导出 | 返回原币、汇率、本位币金额和本位币代码；修复构造器参数不匹配导致的编译失败；保留合法的零金额 |
| 合同与发票编辑 | 表单回填和提交币种、汇率；普通编辑保留已保存快照，兼容旧客户端省略币种字段；明确改变日期、币种或汇率时重新校验有效汇率 |
| 合同历史 | 新版本记录币种、汇率和本位币金额，比较结果包含币种金额变更；恢复为新草稿时保留快照；旧版本缺失字段时按账套本位币兼容 |
| 合同绑定订单 | 采购和销售都校验币种一致；历史空币种按账套本位币解释，不能绕过校验 |
| 单据展示与打印 | 合同金额按单据币种显示，详情和历史展示本位币金额；发票列表、编辑与打印显示币种和汇率 |
| 汇兑报表 | 展示尾差、损益合计、凭证金额/历史折算口径；本页净额按收益为正汇总，付款损失取反；显示本页净尾差及账套本位币 |
| 读取权限 | 合同/发票经办权限可以读取所需币种和汇率，报表查看权限可以读取本位币；币种配置写权限不变 |
| 浏览器回归入口 | 新增一次性 MySQL 运行脚本和两条多币种流程；报告记录 Git HEAD 和工作区是否有未提交改动 |

本轮延续并验证了原有 V167/V168、期末调汇依据、核销金额分摊、往来对账、供应商退货敞口和本位币保护修改；没有把这些原有实现重复计为本轮新增功能。
